# Tasneem's Portfolio

Static React + Vite portfolio. No backend or database is required.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Edit the portfolio content in `frontend/src/utils/constants.js`. The contact
form opens the visitor's email app, and GitHub repositories and stats load
directly from GitHub's public API.

See `frontend/README.md` for build and deployment instructions.
